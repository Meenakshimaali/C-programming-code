# Basic C Programming Codes

This repository contains a collection of basic C programming examples.  
These programs are useful for beginners who are learning C language.

## 📌 Topics Covered
- Input / Output Programs
- If-Else Conditions
- Loops (for, while, do-while)
- Functions
- Arrays
- Strings
- Number Programs (Prime, Armstrong, etc.)

## 💻 Example Programs
- Prime Number Check
- Armstrong Number
- Factorial Program
- Fibonacci Series
- Binary Conversion
- Pattern Printing

## 🎯 Purpose
This repository is created for practice and learning basic concepts of C programming.
